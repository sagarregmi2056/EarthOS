# 🌍 EarthOS
**An open-source operating system for planet-scale sustainability monitoring.**

## 🚀 Mission
> *"Make Earth observable, optimizable, and collaborative in real-time."*

## ✨ MVP Goals
- [ ] Real-time pollution heatmap (NASA/OpenAQ)
- [ ] Crowdsourced data submission (CitizenNode)
- [ ] 3D globe visualization (CesiumJS)

## 🛠️ Quick Start
```bash
# Install
npm install

# Run dev server
npm run dev
